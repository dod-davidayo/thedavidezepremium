Developer notes

Paystack integration placeholder

Prepared for a Nigerian business. The blocks below describe exactly what must be built before this becomes a real payment page.

1 — Verify callback server-side. The Paystack signature header (x-paystack-signature) must be verified against your secret key on your own server. Never trust a client-side "success" response.

2 — Initialise the transaction on the server. Call POST https://api.paystack.co/transaction/initialize from your backend with the amount in kobo, the customer's email and a callback URL. Return only the authorization_url to the browser.

3 — Redirect and verify. After Paystack redirects back, call GET /transaction/verify/:reference on the server, confirm status === "success" and the amount matches, then mark the booking deposit as paid in your database.

4 — Keys. Public key (pk_…) may appear in the browser. The secret key (sk_…) must live only in server environment variables — never in config.js, never in a repository.

// server-side (Node.js example) — NOT part of this static build
// npm i paystack-node express

const Paystack = require("paystack-node")(process.env.PAYSTACK_SECRET_KEY);

app.post("/api/bookings/:ref/pay", async (req, res) => {
  const booking = await db.bookings.findByRef(req.params.ref);
  if (!booking) return res.status(404).json({ error: "Booking not found" });

  const { body } = await Paystack.initializeTransaction({
    amount: booking.deposit * 100,          // Paystack expects kobo
    email:  booking.email,
    reference: booking.ref + "-" + Date.now(),
    callback_url: `${process.env.SITE_URL}/payment?status=return`,
    metadata: { ref: booking.ref, purpose: "booking-deposit" }
  });
  res.json({ authorization_url: body.data.authorization_url });
});

app.get("/api/payments/verify/:reference", async (req, res) => {
  const { body } = await Paystack.verifyTransaction({ reference: req.params.reference });
  if (body.data.status !== "success") return res.status(402).json({ paid: false });

  // Verify the amount matches the booking deposit before trusting it
  const booking = await db.bookings.findByRef(body.data.metadata.ref);
  if (body.data.amount !== booking.deposit * 100) {
    return res.status(400).json({ error: "Amount mismatch" });
  }
  await db.bookings.markDepositPaid(booking.ref, body.data.reference);
  res.json({ paid: true, balance: booking.balance });
});

Configuration lives in CONFIG.commercial.payment in js/config.js. Set enabled: true and add your public key once the backend exists.
